# Wiki

[Office user guides](README.md)

Open **Wiki**, press `g 6`, or enter `:wiki`. Choose **New page**, give it a title, and write in Markdown. Use colons to organize related pages by namespace, as in `projects:launch`. Choose **Save** for the first copy.

## Read, edit, and link pages

Saved pages open in Read view. Choose **Edit source** or press `i` to edit the Markdown, then choose **View page** to return to the rendered page. Use `[[projects:launch]]` to link to a page by its full title. **Backlinks** below the page show other pages that link to that title.

The editor supports a subset of Markdown, including headings, paragraphs, simple bullets, bold, inline and fenced code, HTTP and mailto links, and blockquotes. Wiki links are title-based. If you rename a page, update links that use the old title. Use [Connections](connections.md) to link a page to an item in any app or to keep a link stable across title changes.

## Bring in pages and review revisions

Use **Import** in Wiki to add a Markdown or text file. **Export** downloads the current page as `.md`. For earlier saved versions, choose **History**, select a revision, then choose **Restore this content**.
