# Workspace and settings

[Office user guides](README.md)

Choose **Settings** in the sidebar or enter `:settings`. Select a category to open its controls. On a narrow screen, use the **Settings categories** disclosure. With keyboard focus in the category list, use Up/Down or Home/End and Enter or Space to open a category. Tab moves into its controls.

| Category | What you can change |
| --- | --- |
| **Appearance** | In **Look & feel**, choose a light, dark, or system theme, an accent color, comfortable or compact density, and whether dates show elapsed time. |
| **Mail** | Set the default reading format and outgoing account, download message bodies for offline use, change send confirmation, customize list appearance, and manage junk and recovery settings. See [Mail](mail.md). |
| **Mail Rules** | Set up automatic Inbox routing. See [Mail rules and junk](mail-rules-and-junk.md). |
| **Accounts** | Add, authorize, repair, or remove accounts and configure Google integration. See [Accounts and sync](accounts-and-sync.md). |
| **Activity Log** | Choose how much diagnostic detail is retained. See [Activity and troubleshooting](activity.md). |
| **Connections** | Set the maximum number of link suggestions and sort them by title or date modified. See [Connections](connections.md). |
| **Keyboard** | Remap single-character actions. See [Keyboard navigation and commands](keyboard-navigation.md). |
| **Backups** | Prepare a backup or restore into an empty workspace. See [Backups and moving Office](backups.md). |
| **Swipe Actions** | Set left and right swipe actions separately for mail and other items. |
| **Updates** | Check the installed version and available releases. See [Updates](updates.md). |

Use the category's **Save** button where provided.

Elapsed-time labels are on by default and refresh once a minute while the page is visible. They appear beside the original date, for example, “Nov 4, 10:30 AM (5 minutes ago).”

## Arrange the workspace

On desktop, drag the dividers to resize the application sidebar and item list. You can also focus a divider and use Left and Right. Narrow the sidebar to collapse it to icons, or widen it to show labels. The layout can collapse automatically in a smaller window. In the collapsed sidebar, open the Mail folder panel to browse accounts and folders.

Choose **Full Screen** for a selected item, or press `z` in normal mode. Choose **Exit Full Screen** or press Escape in normal mode to return. The header and activity bar remain accessible.

On a phone, open **Menu** for apps or **Folders** in Mail. Open an item to read or edit it, then use **Back to list** to return. Look under **More**, **More actions**, or **Formatting** for controls that collapse on narrow screens.

## Use swipe actions

On a touchscreen or with a pen, swipe across an item row. By default, left uses the normal delete action and right is off. Mail can also archive, open the folder picker for a synced message, or mark a message read or unread. Other items offer Delete or Off. To change these defaults, open **Settings → Swipe Actions**, set each direction, and choose **Save swipe actions**.
