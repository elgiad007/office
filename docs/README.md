# Office user guides

Start with [Getting started](getting-started.md) to set up your workspace, create your first item, and find your way around Office.

## Apps

| App | What you can do |
| --- | --- |
| [Mail](mail.md) | Read, write, send, file, search, and export mail. |
| [Calendar](calendar.md) | Plan local events and view synced calendars. |
| [Tasks](tasks.md) | Track work by due date, priority, and completion status. |
| [Contacts](contacts.md) | Keep a local address book and exchange vCards. |
| [Documents](documents.md) | Write formatted documents, print, and restore earlier revisions. |
| [Wiki](wiki.md) | Organize Markdown pages with namespaces, links, and backlinks. |
| [Sheets](sheets.md) | Work with small spreadsheets, formulas, and CSV files. |
| [Lists](lists.md) | Create named checklists and track progress. |
